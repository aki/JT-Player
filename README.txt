========================================
 JT Player 静听
 本地 HiFi 音乐播放器
========================================

版本：0.1.0
平台：Windows x64
仓库：git@github.com:aki/JT-Player.git

----------------------------------------
一、简介
----------------------------------------
JT Player（静听）是一款本地 HiFi 风格音乐播放器，
支持主流音频格式，界面参考录音室机架/CD 机舱设计，
提供歌词同步、播放进度恢复、DSP 均衡器等功能。

----------------------------------------
二、功能
----------------------------------------
1. 播放格式
   MP3 / WAV / FLAC / OGG / M4A / AAC / Opus / WebM 等

2. 播放列表
   - 打开文件 / 文件夹，支持拖拽添加
   - 单击选中，Ctrl 多选，Shift 连选，双击播放
   - 右键：播放 / 删除 / 清空（清空与删除需确认）
   - 搜索定位（不隐藏列表，只高亮并跳转）
   - 添加歌曲后自动滚动到新加入位置
   - 列表与设置本地持久化，下次启动自动恢复

3. 播放控制
   - 上一首 / 播放暂停 / 下一首 / 循环模式
   - 循环：单曲循环 → 随机 → 列表循环
   - 波形进度点击、拖拽定位
   - 播放进度保存，重新打开可接着上次位置播
   - 设置中可开启「打开程序自动播放」

4. 歌词
   - 优先读取音频同目录同名 .lrc
   - 其次读取标签内嵌歌词
   - 可联网搜索网易云 / QQ 音乐歌词
   - 歌词从第一句起完整显示，当前句高亮
   - 可调字号（12–50px）、当前歌词颜色
   - 歌词时间偏移可调（-2000ms ~ +2000ms）
   - 网络歌词缓存目录：系统临时目录 JTPlayer-lyrics

5. DSP / 均衡器
   - DSP 预设：FLAT / VOCAL / CLASSIC / JAZZ / ROCK / HEADPHONE
   - 5 段 EQ：60Hz / 230Hz / 910Hz / 4kHz / 14kHz
   - 每段 -12 ~ +12 dB，支持开关与自定义

6. 界面
   - HiFi 设备面板风格
   - 封面、VU 表、频谱、音频元数据
   - 窗口默认最大化
   - 点击左上角「JT Player」打开设置

----------------------------------------
三、安装与运行
----------------------------------------
方式一：Release 安装版
  运行 release\JT Player-0.1.0-win-setup.exe
  安装后从桌面或开始菜单启动「JT Player 静听」

方式二：Release 便携版
  双击 release\JT Player-0.1.0-win-portable.exe

方式三：源码启动
  1. 安装 Node.js（建议 20 或更高）
  2. 在项目目录执行：
       npm install
       npm start
     或双击：启动 JT Player.bat

方式四：开发模式
       npm run dev

注意：不要直接双击 node_modules 里的 electron.exe，
必须通过启动脚本或 npm start（需带上项目目录参数）。

----------------------------------------
四、快捷键
----------------------------------------
Space          播放 / 暂停
左右方向键      快退 / 快进 5 秒
上下方向键      音量增减
N / P          下一首 / 上一首
Delete         删除选中歌曲（需确认）
Esc            关闭弹窗 / 取消

----------------------------------------
五、打包 Release
----------------------------------------
需要真实 Node.js（非仅 Electron 运行时）：

  node scripts/build-release.js

产物输出到 release\ 目录：
  - JT Player-<版本>-win-setup.exe  安装版
  - JT Player-<版本>-win-portable.exe 便携版

也可使用：
  npm run build:release

----------------------------------------
七、说明与限制
----------------------------------------
- 只恢复本地文件路径列表；磁盘上文件被移动后可能无法播放
- WMA、APE、DSD 等格式暂不支持
- 网络歌词依赖接口可用性，请以本地 .lrc 为准
- 进度保存在用户数据目录，例如：
    C:\Users\<用户>\AppData\Roaming\jt-player\jt-player-state.json
- 本程序未做代码签名，系统可能提示未知发布者
